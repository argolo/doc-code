Cada projeto pede um nível de autonomia. O doc-code deixa a estratégia explícita no repositório, para que cada execução entregue o resultado esperado sem repetir flags.

01 / escopo

O tamanho certo para cada rotina

Mudanças do Git, arquivos específicos ou o repositório todo. Você escolhe o alcance uma vez e não pensa nisso de novo.

selection = "repository"
02 / autonomia

Do preview ao apply direto

Use revisão quando ela agrega valor ou aplique automaticamente para transformar documentação em uma etapa natural do fluxo.

output = "apply"
03 / padrão

A mesma linguagem em todo lugar

Idioma, formato e cobertura vivem no projeto. O resultado fica coerente, independentemente de quem executa.

python_format = "google"

Escolha seu
provedor de IA.

Conecte um modelo hospedado quando quiser começar rapidamente ou rode a geração localmente para manter o código no seu ambiente.

OPENAI

Modelos de ponta

Use a API da OpenAI para gerar documentação precisa com o modelo escolhido pelo projeto.

provider = "openai"
GEMINI

Uma alternativa direta

Use Gemini com a mesma experiência de configuração e revisão no terminal.

provider = "gemini"
OLLAMA

Privacidade local

Rode modelos de código localmente, sem credencial e com o código sob seu controle.

provider = "ollama"

Um arquivo define
o jeito do time.

Versione um .doc-code.toml junto ao código. Ele transforma preferências dispersas em um padrão compartilhado, reproduzível e simples de usar.

Configuração por repositório

A complexidade fica aqui.
Não no comando.

Modelos, escopo, cobertura, formato e automação ficam declarados no projeto. Para o dia a dia, basta doc-code.

[ai]
provider = "ollama"
models = ["gemma4:e4b", "qwen2.5-coder:14b", "gemma4:12b-mlx"]
endpoint = "http://localhost:11434/api/generate"
max_input_tokens = 3048
context_window_tokens = 16384
max_output_tokens = 512
temperature = 0.1
timeout_seconds = 180

[documentation]
selection = "repository"
coverage = "missing"
request_scope = "symbol"
language = "pt-BR"
python_format = "google"
javascript_format = "jsdoc"
output = "apply"
confirm = false

[limits]
max_files_per_request = 50
max_file_bytes = 1000000
exclude = ["**/node_modules/**", "**/dist/**", "**/build/**", ...]

Um comando.
O fluxo que você escolheu.

O projeto decide as regras; o time não precisa lembrá-las. Da execução assistida à automação, a experiência é sempre a mesma: doc-code.

01 / definir

Declare a política do projeto

doc-code config init

Configure uma vez como o projeto seleciona, escreve e aplica documentação.

02 / versionar

Compartilhe o padrão

.doc-code.toml

O mesmo arquivo acompanha o repositório e elimina decisões repetidas em cada máquina.

03 / executar

Rode sem pensar em flags

doc-code

A ferramenta faz exatamente o que a configuração do projeto determina.
